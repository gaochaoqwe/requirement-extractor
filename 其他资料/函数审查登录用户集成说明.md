# 函数审查功能 - 登录用户集成说明

## 修改概述

将函数审查功能中的"测试人员姓名"输入改为自动使用当前登录用户的信息，无需手动输入。

## 修改内容

### 1. 后端修改

**文件**: `D:\code\requirement_extractor\backend\app\codeReview\ConfigurationItem\api\endpoints\start_analysis.py`

#### 主要变更：

1. **添加Request导入**
   ```python
   from fastapi import APIRouter, Depends, HTTPException, BackgroundTasks, Request
   ```

2. **修改StartAnalysisRequest模型**
   - 移除了 `tester_name` 字段（不再从前端传入）
   - 添加注释说明从session获取

3. **修改start_analysis函数**
   - 添加 `request: Request` 参数
   - 从session中获取当前登录用户信息：
     ```python
     # 从session中获取当前登录用户信息
     tester_name = request.session.get('display_name', None)
     if not tester_name:
         # 如果没有登录，使用username作为备选
         tester_name = request.session.get('username', '未知用户')
     
     log_info(f"当前登录用户: {tester_name}", "start_analysis")
     ```

4. **传递用户信息到后台任务**
   - 使用从session获取的 `tester_name` 传递给后台任务

### 2. 前端修改

**文件**: `D:\code\requirement_extractor\frontend_vue\src\views\codeReview\configurationItem\ConfigurationItemCodeReview.vue`

#### 主要变更：

1. **导入auth store**
   ```javascript
   import { useAuthStore } from '@/stores/auth';
   const authStore = useAuthStore();
   ```

2. **移除测试人员输入框**
   - 删除了整个测试人员输入的UI组件（第46-58行）
   - 移除了 `testerName` 响应式变量

3. **添加登录检查**
   ```javascript
   // 检查是否已登录
   if (!authStore.isAuthenticated || !authStore.user) {
     message.value = '请先登录';
     messageType.value = 'warning';
     ElMessage.warning('请先登录后再进行代码审查');
     // 跳转到登录页面
     router.push('/login');
     return;
   }
   ```

4. **修改请求数据**
   - 从请求数据中移除 `tester_name` 字段
   - 后端会自动从session获取

## 工作流程

### 修改前
1. 用户上传代码文件
2. **用户手动输入测试人员姓名**
3. 点击开始审查
4. 后端接收测试人员姓名并记录到日志

### 修改后
1. 用户登录系统（使用登录模块）
2. 用户上传代码文件
3. 点击开始审查（无需输入姓名）
4. 前端检查登录状态
5. 后端从session中自动获取当前登录用户的 `display_name`
6. 将用户名记录到日志文件中

## 数据流

```
前端 (ConfigurationItemCodeReview.vue)
  ↓
检查 authStore.isAuthenticated
  ↓
发送请求 (不包含tester_name)
  ↓
后端 (start_analysis.py)
  ↓
从 request.session 获取 'display_name'
  ↓
传递给后台任务 (run_analysis_task)
  ↓
记录到日志文件 (concurrent_logger.py)
```

## 兼容性说明

- **session数据来源**: 登录模块在用户登录时会设置session：
  ```python
  request.session['user_id'] = user['id']
  request.session['username'] = user['username']
  request.session['display_name'] = user['display_name']
  ```

- **备用方案**: 如果 `display_name` 不存在，会使用 `username`，如果都不存在则使用"未知用户"

## 日志文件位置

日志文件会记录测试人员信息，位置：
```
backend/app/codeReview/ConfigurationItem/logs/task_{task_id}/logs/
  - task_summary.log (汇总日志)
  - function_*.log (函数审查线程日志)
  - fpga_*.log (FPGA审查线程日志)
```

每个日志文件头部会包含：
```
=== 代码审查任务汇总日志 ===
任务ID: xxx
文件ID: xxx
测试人员: {从session获取的display_name}
开始时间: xxxx-xx-xx xx:xx:xx
```
