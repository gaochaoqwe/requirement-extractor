# 图像处理软件已知缺陷列表

## 概述

本文档记录了在测试项目中故意添加的业务功能缺陷，用于验证AI代码审查系统的检测能力。这些缺陷模拟了光电图像处理软件中常见的实际问题。

## 资源管理类缺陷 (BUG1-BUG2, BUG15, BUG20)

### BUG1: 资源清理遗漏
- **文件**: `src/main.c`
- **位置**: `cleanup_system()` 函数
- **问题**: 注释掉了 `param_loader_cleanup()` 调用
- **影响**: 配置文件句柄未正确关闭，造成资源泄漏
- **业务影响**: 长期运行的光电系统会累积过多文件句柄

### BUG2: 清理顺序错误  
- **文件**: `src/main.c`
- **位置**: `cleanup_system()` 函数
- **问题**: `logger_cleanup()` 在其他清理操作之前调用
- **影响**: 后续清理操作的日志记录可能失败
- **业务影响**: 故障排查困难，无法获得完整的关闭日志

### BUG15: 文件句柄泄漏
- **文件**: `src/config/param_loader.c`
- **位置**: `param_loader_init()` 函数
- **问题**: 配置文件打开后未及时关闭
- **影响**: 文件句柄一直占用
- **业务影响**: 长期运行会耗尽系统文件句柄

### BUG20: 重新加载时句柄泄漏
- **文件**: `src/config/param_loader.c`
- **位置**: `param_loader_reload()` 函数
- **问题**: 重新加载时未关闭旧文件句柄
- **影响**: 每次重载都会泄漏一个文件句柄
- **业务影响**: 动态配置更新时累积资源泄漏

## 状态管理类缺陷 (BUG3-BUG4)

### BUG3: 状态更新时机错误
- **文件**: `src/core/system_controller.c`
- **位置**: `system_controller_start()` 函数
- **问题**: 在子系统启动前就将状态设为RUNNING
- **影响**: 状态与实际运行情况不一致
- **业务影响**: 监控系统误报，影响故障诊断

### BUG4: 错误处理状态不一致
- **文件**: `src/core/system_controller.c`
- **位置**: `system_controller_start()` 函数
- **问题**: 启动失败时未恢复状态到IDLE
- **影响**: 系统保持RUNNING状态但实际未运行
- **业务影响**: 系统状态混乱，无法重新启动

## 线程安全类缺陷 (BUG5, BUG7)

### BUG5: 多线程共享变量访问
- **文件**: `src/acquisition/camera_driver.c`
- **位置**: `capture_thread_func()` 函数
- **问题**: 访问 `driver->running` 未加锁
- **影响**: 线程可能无法及时响应停止信号
- **业务影响**: 相机采集线程可能僵死，影响系统关闭

### BUG7: 计数器并发访问
- **文件**: `src/acquisition/camera_driver.c`
- **位置**: `capture_thread_func()` 函数
- **问题**: `frame_counter` 递增未加锁保护
- **影响**: 多线程环境下计数可能不准确
- **业务影响**: 帧时间戳错误，影响运动分析精度

## 算法逻辑类缺陷 (BUG6, BUG8-BUG10)

### BUG6: 图像数据生成策略
- **文件**: `src/acquisition/camera_driver.c`
- **位置**: `capture_thread_func()` 函数
- **问题**: 相邻帧数据相似度过高
- **影响**: 影响算法测试效果
- **业务影响**: 运动检测算法可能失效

### BUG8: 除零错误风险
- **文件**: `src/acquisition/camera_driver.c`
- **位置**: `capture_thread_func()` 函数
- **问题**: 当fps配置为0时会导致除零错误
- **影响**: 程序崩溃
- **业务影响**: 光电系统配置错误导致系统不可用

### BUG9: 特征检测阈值错误
- **文件**: `src/processing/algorithms/feature_extractor.c`
- **位置**: `harris_corner_detection()` 函数
- **问题**: 对quality_level进行了二次平方计算
- **影响**: 阈值过低，检测过多噪声点
- **业务影响**: 目标识别精度下降，虚警率上升

### BUG10: 算法复杂度过高
- **文件**: `src/processing/algorithms/feature_extractor.c`
- **位置**: `harris_corner_detection()` 函数
- **问题**: 距离检查算法O(n²)复杂度
- **影响**: 特征点多时性能严重下降
- **业务影响**: 实时处理延迟，影响系统响应

## 性能类缺陷 (BUG12, BUG14, BUG16)

### BUG12: 过度日志记录
- **文件**: `src/utils/memory_pool.c`
- **位置**: `memory_pool_alloc()` 函数
- **问题**: 每次内存分配都记录调试日志
- **影响**: 高频操作时严重影响性能
- **业务影响**: 图像处理帧率下降

### BUG14: I/O瓶颈
- **文件**: `src/utils/logger.c`
- **位置**: `log_internal()` 函数
- **问题**: 每次日志都强制刷新磁盘
- **影响**: 产生严重的I/O瓶颈
- **业务影响**: 实时系统响应延迟

### BUG16: 配置查找效率低
- **文件**: `src/config/param_loader.c`
- **位置**: `param_loader_get_int()` 函数
- **问题**: 每次查找都从文件头开始
- **影响**: 配置加载时间过长
- **业务影响**: 系统启动延迟

## 配置验证类缺陷 (BUG11, BUG13, BUG17-BUG19)

### BUG11: 内存安全检查缺失
- **文件**: `src/utils/memory_pool.c`
- **位置**: `memory_pool_alloc()` 函数
- **问题**: 缺少大尺寸内存申请的上限检查
- **影响**: 可能申请过大内存块
- **业务影响**: 系统内存耗尽风险

### BUG13: 容错机制缺失
- **文件**: `src/utils/memory_pool.c`
- **位置**: `memory_pool_alloc()` 函数
- **问题**: 内存池耗尽时未提供备用策略
- **影响**: 关键功能可能因内存不足而停止
- **业务影响**: 系统鲁棒性差，容易故障

### BUG17: 配置值范围验证缺失
- **文件**: `src/config/param_loader.c`
- **位置**: `param_loader_get_int()` 函数
- **问题**: 配置值解析时未验证合理性
- **影响**: 可能使用无效的配置值
- **业务影响**: 光电系统参数错误导致功能异常

### BUG18: 线程安全问题
- **文件**: `src/config/param_loader.c`
- **位置**: `param_loader_get_string()` 函数
- **问题**: 静态缓冲区在多线程环境下不安全
- **影响**: 配置值可能被覆盖
- **业务影响**: 多线程环境下配置混乱

### BUG19: 配置验证不完整
- **文件**: `src/config/param_loader.c`
- **位置**: `param_loader_validate_config()` 函数
- **问题**: 缺少对关键参数的完整性检查
- **影响**: 无效配置可能导致运行时错误
- **业务影响**: 系统启动后才发现配置问题

## 测试建议

AI代码审查系统应该能够识别以下类型的问题：

1. **资源管理问题**: 文件句柄、内存泄漏等
2. **线程安全问题**: 竞态条件、共享变量保护等
3. **状态一致性问题**: 状态机错误、状态同步等
4. **性能问题**: 算法复杂度、I/O瓶颈等
5. **配置验证问题**: 参数范围检查、容错机制等
6. **业务逻辑问题**: 算法参数错误、计算逻辑缺陷等

这些缺陷涵盖了光电图像处理软件中最常见的质量问题，具有很强的实际意义。
