# 图像处理软件调用链路说明

## 1. 系统架构概述

本图像处理软件采用分层模块化架构，包含以下主要模块：

```
┌─────────────────────────────────────────────────────────────┐
│                         主程序层                              │
│                        main.c                               │
└─────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│                         核心控制层                            │
│              system_controller.c                            │
│              image_manager.c                                │
│              task_scheduler.c                               │
└─────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│                         业务处理层                            │
│    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│    │图像采集模块   │  │图像处理模块   │  │图像显示模块   │          │
│    │camera_driver│  │algorithms  │  │renderer     │          │
│    │frame_buffer │  │filters     │  │overlay_mgr  │          │
│    │sync_manager │  │enhancement │  │output_fmt   │          │
│    └─────────────┘  └─────────────┘  └─────────────┘          │
└─────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│                         工具支撑层                            │
│    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│    │内存管理     │  │日志系统     │  │配置管理     │          │
│    │memory_pool  │  │logger       │  │param_loader │          │
│    │             │  │             │  │settings_mgr │          │
│    └─────────────┘  └─────────────┘  └─────────────┘          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 主要调用链路

### 2.1 系统启动流程

```
main() 
├── initialize_system()
│   ├── logger_init()                          // 初始化日志系统
│   ├── param_loader_init()                    // 加载配置文件
│   ├── system_controller_create()             // 创建系统控制器
│   └── system_controller_init()               // 初始化系统控制器
│       ├── memory_pool_create()               // 创建内存池
│       ├── settings_manager_create()          // 创建设置管理器
│       ├── task_scheduler_create()            // 创建任务调度器
│       ├── image_manager_create()             // 创建图像管理器
│       ├── camera_driver_create()             // 创建相机驱动
│       └── renderer_create()                  // 创建渲染器
├── system_controller_start()                  // 启动系统
│   ├── camera_driver_start()                  // 启动相机
│   │   ├── sync_manager_start()               // 启动同步管理器
│   │   └── pthread_create(capture_thread)     // 启动采集线程
│   ├── task_scheduler_start()                 // 启动任务调度器
│   └── renderer_start()                       // 启动渲染器
└── main_loop()                                // 进入主循环
```

### 2.2 图像处理主流程

```
main_loop()
└── system_controller_process()
    ├── camera_driver_capture_frame()          // 捕获图像帧
    │   └── frame_buffer_get_frame()           // 从帧缓冲区获取帧
    ├── image_manager_process_frame()          // 处理图像帧
    │   ├── feature_extractor_extract()        // 特征提取
    │   │   ├── harris_corner_detection()      // Harris角点检测
    │   │   │   ├── memory_pool_alloc()        // 分配计算内存
    │   │   │   ├── edge_detector_process()    // 边缘检测
    │   │   │   └── math_utils_*()             // 数学计算工具
    │   │   └── fast_corner_detection()        // FAST角点检测
    │   ├── object_detector_detect()           // 目标检测
    │   │   ├── noise_filter_process()         // 噪声滤波
    │   │   ├── histogram_equalizer_process()  // 直方图均衡化
    │   │   └── brightness_adjuster_process()  // 亮度调整
    │   └── motion_tracker_track()             // 运动跟踪
    │       ├── feature_matcher_match()        // 特征匹配
    │       └── kalman_filter_predict()        // 卡尔曼滤波预测
    ├── renderer_display_image()               // 显示图像
    │   ├── overlay_manager_add_overlays()     // 添加覆盖层
    │   └── output_formatter_format()          // 格式化输出
    └── task_scheduler_process_tasks()         // 处理任务队列
```

### 2.3 相机采集线程流程

```
capture_thread_func() (独立线程)
├── 循环执行:
│   ├── 模拟硬件采集图像数据
│   ├── memory_pool_alloc()                    // 分配图像内存
│   ├── sync_manager_get_timestamp()           // 获取时间戳
│   ├── frame_buffer_put_frame()               // 将帧放入缓冲区
│   │   └── logger_debug()                     // 记录调试信息
│   └── usleep()                               // 控制采集帧率
└── 线程退出清理
```

### 2.4 错误处理调用链

```
任意函数发生错误
├── logger_error()                             // 记录错误日志
├── 返回错误码 (ERROR_*)
├── 上级函数检查返回值
├── 执行错误恢复策略
│   ├── 释放已分配资源
│   │   ├── memory_pool_free()                 // 释放内存
│   │   └── 其他资源清理
│   ├── 更新系统状态
│   └── 通知相关模块
└── 向上层报告错误状态
```

## 3. 关键交互关系

### 3.1 内存管理交互

- **全局内存池**: 由 `system_controller` 创建，被所有模块共享使用
- **分配路径**: 各模块 → `memory_pool_alloc()` → 内存池分配器
- **释放路径**: 各模块 → `memory_pool_free()` → 内存池管理器
- **统计监控**: `memory_pool_get_stats()` 提供内存使用统计

### 3.2 日志系统交互

- **初始化**: `main()` → `logger_init()` 初始化全局日志系统
- **各级调用**: 所有模块都可调用 `logger_*()` 函数记录日志
- **输出目标**: 同时输出到控制台和日志文件
- **线程安全**: 使用互斥锁保证多线程日志安全

### 3.3 配置管理交互

- **加载配置**: `param_loader_init()` 读取 INI 配置文件
- **参数获取**: 各模块通过 `settings_manager_get_*()` 获取配置参数
- **运行时更新**: 支持运行时动态更新部分配置参数

### 3.4 任务调度交互

- **任务提交**: 各模块向 `task_scheduler` 提交异步任务
- **优先级管理**: 根据任务类型和优先级进行调度
- **状态回调**: 任务完成后通过回调函数通知提交方

## 4. 数据流向

### 4.1 图像数据流

```
硬件相机 → camera_driver → frame_buffer → image_manager
           ↓
    特征提取/目标检测/运动跟踪 (并行处理)
           ↓
    处理结果 → overlay_manager → renderer → 显示设备
```

### 4.2 控制数据流

```
用户输入/配置文件 → settings_manager → 各处理模块
                    ↓
           runtime_parameters → algorithm_controllers
                    ↓
             feedback_data → system_controller
```

### 4.3 状态信息流

```
各子模块状态 → system_controller → 系统状态管理
              ↓
    状态变更事件 → logger → 日志记录/监控系统
```

## 5. 性能关键路径

### 5.1 实时性关键路径

1. **图像采集**: `camera_driver` → `frame_buffer` (≤10ms)
2. **特征提取**: `feature_extractor` 各算法 (≤30ms)
3. **目标检测**: `object_detector` 检测算法 (≤50ms)
4. **图像显示**: `renderer` 渲染输出 (≤16ms, 60fps)

### 5.2 内存使用关键路径

1. **图像缓存**: 最大占用 4K×3K×4通道×10帧 ≈ 480MB
2. **算法计算**: 临时矩阵和中间结果 ≈ 100MB
3. **特征数据**: 最大1000个特征点数据 ≈ 1MB

### 5.3 CPU密集型操作

1. **特征提取**: Harris/FAST角点检测算法
2. **图像滤波**: 卷积、边缘检测等操作
3. **运动跟踪**: 特征匹配和预测算法

## 6. 扩展性设计

### 6.1 模块化设计

- 每个功能模块独立编译，便于单独测试和维护
- 通过统一的接口和数据结构进行模块间通信
- 支持运行时动态加载和卸载特定算法模块

### 6.2 算法插件化

- 特征提取算法可在 Harris 和 FAST 间切换
- 滤波算法支持多种滤波器类型
- 检测算法支持不同的目标检测策略

### 6.3 配置灵活性

- 支持 INI 格式配置文件
- 大部分参数支持运行时调整
- 提供默认配置保证系统基本可用性

这个调用链路设计确保了系统的高性能、可维护性和扩展性，适合用于测试代码审查系统的调用关系分析能力。
