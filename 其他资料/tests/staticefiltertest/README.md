# 静态分析过滤工具测试代码库

## 概述
这个代码库专门用于测试静态分析过滤工具的AI分析能力。代码中故意埋入了一些常见的代码问题，用于验证AI是否能够准确识别和分析这些问题。

## 埋入的问题类型

### 1. 数组越界问题 (array_bounds.c)
**对应规则**: `GJB_R_01_06_08` - 数组禁止越界使用

**埋入的问题**:
- 静态数组越界访问 (第32行: `buffer[5] = 100;`)
- 数组越界读取 (第35行: `printf("Invalid access: %d\n", buffer[6]);`)
- 循环中的数组越界 (第38-40行)
- 动态数组越界访问 (第53-54行)

### 2. 内存释放后使用问题 (memory_usage.c)
**对应规则**: `GJB_R_01_06_16` - 禁止使用已被释放了的内存空间

**埋入的问题**:
- Use-after-free读取 (第35行: `printf("After free: %s\n", data);`)
- Use-after-free写入 (第38行: `strcpy(data, "New data");`)
- 重复释放内存 (第41行: `free(data);`)
- 通过备份指针访问已释放内存 (第60-63行)
- 返回已释放的指针 (第68-76行)

### 3. 未初始化变量使用问题 (uninitialized_vars.c)
**对应规则**: `GJB_R_01_11_01` - 变量禁止未赋值就使用

**埋入的问题**:
- 直接使用未初始化变量 (第22行: `printf("Uninitialized int: %d\n", uninitialized_int);`)
- 计算中使用未初始化变量 (第25行: `int result = uninitialized_int + 10;`)
- 条件判断中使用未初始化变量 (第29行)
- 未初始化变量作为数组索引 (第35行)
- 结构体成员未初始化使用 (第48-54行)
- 指针未初始化使用 (第59-66行)
- 循环累加中使用未初始化变量 (第73-77行)

```bash
# 清理
make clean
```

1. 验证AI能否准确识别埋入的3种类型问题
2. 测试AI分析的准确性和覆盖率
3. 评估静态分析过滤工具的效果
