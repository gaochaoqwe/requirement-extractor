### 1. 主程序模块 (main.c)

#### 功能名称：程序入口与流程控制

#### 功能描述：
- **主要职责**：作为整个测试程序的入口点，协调各个模块的执行流程
- **核心功能**：
  - 初始化程序并显示欢迎信息
  - 调用数学运算模块进行基本计算（加法、乘法）
  - 调用数据处理模块处理整型数组
  - 计算数组平均值并输出结果
  - 执行资源清理操作
- **输入输出**：无命令行参数输入，通过控制台输出程序执行结果
- **业务逻辑**：按顺序执行各模块功能，展示完整的程序执行流程
