## 📋 项目说明

这是一个用于测试全局过滤规则的C代码项目，包含多个故意设计的问题代码，用于验证AI审查和过滤规则是否正常工作。

## 🎯 测试目的

验证以下功能：
1. AI返回的问题原因是否能正确匹配过滤规则
2. 匹配规则的问题是否自动设置为状态3（已过滤）
3. 不匹配规则的问题是否保持状态1（未处理）
4. 前端是否正确显示灰色（过滤）和正常颜色

## 🐛 常见问题

### Q: 所有问题都没有被过滤？
A: 检查：
1. `global_filter_rules.json` 中的规则是否启用（`enabled: true`）
2. 后端是否重启（配置文件修改后需重启）
3. AI返回的问题原因是否包含关键词

### Q: 问题被过滤了但不应该？
A: 检查问题原因的实际文本，可能包含了规则关键词

### Q: OR逻辑规则不工作？
A: 确认 `logic` 字段为 `"OR"` 且至少有一个关键词匹配

## 📝 注意事项

1. AI可能不会对每个函数都报告问题
2. AI报告的问题原因可能与预期略有不同
3. 某些问题可能同时匹配多个规则，只会记录第一个匹配的规则
4. 状态3的问题不会被删除，只是标记为"已过滤"
