# 代码审查系统 - 链路模式优化说明

## 优化时间
2025-10-12

## 优化需求

用户希望链路模式按以下方式显示：

1. **左侧栏**：显示链路名称，可展开显示链路中的函数
   - 函数显示格式：`文件路径->函数名` (例如：`user/user.cpp->userAdd()`)
   - 函数按从上到下的调用顺序显示
   - 点击函数时中间栏显示对应的源代码

2. **中间栏**：显示选中函数的源代码

3. **右侧栏**：显示链路功能描述和问题列表

```javascript
// 格式化函数显示 - 显示格式: 文件路径->函数名
function formatFunctionDisplay(func) {
  const funcName = func.function_name || func.name || func.function || '未知函数'
  
  if (func.file_path) {
    // 显示格式: user/user.cpp->userAdd()
    return `${func.file_path}->${funcName}`
  }
  
  return funcName
}

// 获取函数的提示信息
function getFunctionTooltip(func) {
  const funcName = func.function_name || func.name || func.function || '未知函数'
  const filePath = func.file_path || '未知文件'
  const lines = func.start_line && func.end_line ? ` (行 ${func.start_line}-${func.end_line})` : ''
  
  return `函数: ${funcName}\n文件: ${filePath}${lines}`
}
```

```javascript
async function handleFunctionSelect(selection) {
  const { chain, func, index } = selection
  
  // 获取函数完整信息
  const funcName = typeof func === 'string' ? func : (func.function_name || func.name || func.function)
  const filePath = typeof func === 'object' ? func.file_path : null
  const sourceCode = typeof func === 'object' ? func.source_code : null
  
  // 创建函数节点，包含完整的源代码和链路信息
  const functionNode = {
    id: `${chain.id}_func_${index}`,
    name: funcName,
    type: 'function',
    chain: chain.name,
    chain_description: chain.description,
    order: index + 1,
    file_path: filePath,
    source_code: sourceCode,
    start_line: func.start_line,
    end_line: func.end_line,
    function_description: func.function_description,
    commented_code: func.commented_code,
    problems: chain.problems
  }
  
  // 更新侧边栏模式为 chain_function
  sidebarMode.value = 'chain_function'
  sidebarTitle.value = `链路: ${chain.name}`
}
```

## 关键特性

### 1. 函数显示格式

- **标准格式**：`文件路径->函数名`
- **示例**：`user/user.cpp->userAdd()`
- **优势**：清晰显示函数所在位置

- 帮助理解业务流程

- **链路级别**：功能描述（绿色）
- **函数级别**：当前函数信息（橙色）
- **问题级别**：问题列表（红色）

### 4. 完整源代码显示

- 点击函数立即显示完整源代码
- 不仅是函数定义，而是整个文件内容
- 支持语法高亮和行号
- 可切换查看AI注释版本

## 对比：优化前后

### 优化前

```
左侧：链路树
├─ 系统初始化链路
│  └─ main          ← 只有函数名
│  └─ init
│  └─ load_config
```

**问题**：
- 不知道函数在哪个文件
- 没有调用顺序
- 点击函数源代码显示不正确

### 优化后

```
左侧：链路树
├─ 系统初始化链路
│  └─ src/main.c->main()          ① ← 文件路径+函数名+顺序
│  └─ src/init.c->init()          ②
│  └─ src/config.c->load_config() ③
```

**优势**：
- 清晰显示函数所在文件
- 标识调用顺序
- 源代码完整显示
- 链路功能描述突出显示
