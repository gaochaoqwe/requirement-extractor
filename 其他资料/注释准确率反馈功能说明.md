# 注释准确率反馈功能实现文档

## 功能概述

在函数审查中，当用户点击查看的函数数量超过50%时，自动弹出一个美观的提示框，让用户反馈AI生成注释的准确率。

## 实现内容

### 1. 数据库修改

需要在 Navicat 中执行以下SQL语句：

```sql
-- 在 code_review_tasks 表中添加注释准确率字段
ALTER TABLE code_review_tasks 
ADD COLUMN comment_accuracy_rate VARCHAR(50) NULL COMMENT '注释准确率：50%以下、50%-70%、70%-85%、85%-95%、95%-100%';

-- 添加反馈时间字段
ALTER TABLE code_review_tasks 
ADD COLUMN comment_accuracy_feedback_at DATETIME NULL COMMENT '注释准确率反馈时间';

-- 添加已点击函数数量字段（用于判断是否超过50%）
ALTER TABLE code_review_tasks 
ADD COLUMN clicked_function_count INT DEFAULT 0 COMMENT '已点击查看的函数数量';
```

### 2. 后端修改

#### 2.1 模型更新

**文件：** `backend/app/codeReview/ConfigurationItem/db/models/task.py`

- 添加了 `comment_accuracy_rate` 字段：存储用户反馈的准确率区间
- 添加了 `comment_accuracy_feedback_at` 字段：记录反馈时间
- 添加了 `clicked_function_count` 字段：记录用户点击查看的函数数量
- 更新了 `to_dict()` 方法，包含新字段

#### 2.2 仓库方法更新

**文件：** `backend/app/codeReview/ConfigurationItem/db/repository/task_repo.py`

新增方法：
- `increment_clicked_function_count(task_id)`: 增加已点击函数计数
- `update_comment_accuracy(task_id, accuracy_rate)`: 更新注释准确率反馈
- `get_total_function_count(task_id)`: 获取任务的总函数数量

#### 2.3 API接口

**文件：** `backend/app/codeReview/ConfigurationItem/api/endpoints/comment_accuracy.py`

新增接口：

1. **POST** `/api/codeReview/{task_id}/comment_accuracy_feedback`
   - 提交注释准确率反馈
   - 请求体：`{ "accuracy_rate": "50%-70%" }`
   - 返回：提交结果

2. **POST** `/api/codeReview/{task_id}/increment_clicked_function`
   - 增加已点击函数计数
   - 返回：是否需要弹出反馈框 (`should_show_feedback`)

3. **GET** `/api/codeReview/{task_id}/comment_accuracy_status`
   - 获取反馈状态
   - 返回：点击数量、总函数数、是否已反馈等信息

#### 2.4 路由注册

**文件：** `backend/app/codeReview/ConfigurationItem/api/router.py`

- 已注册 `comment_accuracy_router`

### 3. 前端修改

- 监听选中节点变化，当点击函数节点时调用 `incrementClickedFunction()`
- 根据后端返回的 `should_show_feedback` 决定是否弹出反馈框
- 添加反馈提交处理函数

## 工作流程

1. **用户点击函数节点**
   - 前端监听到 `selectedNode` 变化
   - 如果是函数类型节点，调用 `incrementClickedFunction()` API

2. **后端计数和判断**
   - 增加 `clicked_function_count` 计数
   - 计算点击百分比：`clicked_count / total_functions * 100`
   - 如果刚好超过50%（从≤50%变为>50%），返回 `should_show_feedback: true`

3. **弹出反馈框**
   - 前端收到 `should_show_feedback: true`
   - 显示美观的反馈对话框
   - 用户选择准确率区间

4. **提交反馈**
   - 调用 `comment_accuracy_feedback` API
   - 后端更新 `comment_accuracy_rate` 和 `comment_accuracy_feedback_at`
   - 显示感谢消息

5. **防重复弹出**
   - 如果已经反馈过（`comment_accuracy_rate` 不为空），不再弹出
   - 不再增加点击计数

## 特性

✅ **智能触发**：只在点击函数超过50%时弹出一次  
✅ **美观设计**：渐变图标、动画效果、清晰的视觉层次  
✅ **用户友好**：可以选择"暂不反馈"，不强制用户立即反馈  
✅ **防重复**：已反馈后不再弹出  
✅ **数据持久化**：反馈数据保存在数据库中  
✅ **进度显示**：实时显示已查看函数的百分比

## 注意事项

- 只针对**函数审查**（不是链路审查、功能审查）
- 只在点击**函数节点**时计数（不包括文件节点）
- 每个任务只弹出一次反馈框
- 反馈是可选的，用户可以选择"暂不反馈"
