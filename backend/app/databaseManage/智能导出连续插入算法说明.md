# 智能导出连续插入算法说明

## 背景问题

在智能导出功能中，当一个测试项匹配到多个测试用例时，需要将这些新用例插入到Excel的测试用例单中，并且要求：

1. **连续性**：同一个测试项的所有新用例必须连续排列
2. **就近性**：新用例要紧跟在原有测试项的最后一行之后
3. **顺序性**：按照原有测试项在表单中的顺序处理插入

## 遇到的问题

### 问题1：非连续插入
**现象**：同一测试项的多个新用例被其他测试项的用例分隔开了
```
用户身份验证功能（原有）
用户身份验证功能（新增1）
用户身份验证功能（性能测试）（原有）  ← 插入了其他测试项
用户身份验证功能（新增2）              ← 第二个新用例被分隔了
```

**原因分析**：
- 使用`_batch_insert_rows`方法，通过逆序排序后逐一插入
- `worksheet.insert_rows(row_idx)`每次只插入一行，会导致后续行号发生偏移
- 计算插入位置时没有考虑到Excel内部的行号动态调整

### 问题2：位置计算不准确
**现象**：插入位置计算错误，导致新用例出现在错误的位置
**原因**：Excel在插入行后会自动调整后续行的行号，但我们的算法没有实时跟踪这些变化

## 解决方案

### 核心思路

1. **预先匹配**：在插入之前先分析所有测试项，确定哪些需要插入新用例
2. **维护工作副本**：创建`working_groups`字典来动态跟踪每个测试项的当前位置
3. **有序处理**：按照测试项在表单中的原始顺序（first_row从小到大）逐个处理
4. **一次性连续插入**：对每个测试项，使用`worksheet.insert_rows(start_row, count)`一次性插入所有新用例
5. **实时更新位置**：每次插入后，更新所有后续测试项在`working_groups`中的位置信息

### 算法流程

```python
# 1. 预先匹配所有测试项
all_matches = {}
for test_item_name, group_info in test_item_groups.items():
    matched_records = cls._match_test_items(test_item_name, asset_data)
    if matched_records:
        all_matches[test_item_name] = matched_records

# 2. 创建工作副本来跟踪位置变化
working_groups = {k: v.copy() for k, v in test_item_groups.items()}

# 3. 按first_row正序处理
while all_matches:
    # 找到下一个要处理的测试项（first_row最小的）
    next_test_item = min(all_matches.keys(), 
                        key=lambda x: working_groups[x]['first_row'])
    
    # 计算插入位置
    next_group_info = working_groups[next_test_item]
    insert_start_row = next_group_info['last_row'] + 1
    
    # 一次性连续插入该测试项的所有用例
    matched_records = all_matches[next_test_item]
    cls._insert_continuous_rows(worksheet, insertions, progress_callback)
    
    # 更新所有后续测试项的位置
    rows_inserted = len(matched_records)
    for item_name, item_info in working_groups.items():
        if item_name != next_test_item and item_info['first_row'] >= insert_start_row:
            item_info['first_row'] += rows_inserted
            item_info['last_row'] += rows_inserted
    
    # 移除已处理的测试项
    del all_matches[next_test_item]
```

## 关键创新

### 1. 一次性连续插入方法 `_insert_continuous_rows`

**核心特点**：
- 使用`worksheet.insert_rows(start_row, count)`一次性插入多行
- 避免了逐行插入导致的行号偏移问题
- 确保同一测试项的所有新用例连续排列

```python
@classmethod
def _insert_continuous_rows(cls, worksheet, insertions: List[Tuple], 
                           progress_callback: Callable[[int, str], None] = None):
    """连续插入同一测试项的多行用例（避免位置错乱）"""
    
    # 提取插入信息
    insert_start_row = insertions[0][0]
    total_insertions = len(insertions)
    
    # 一次性插入连续的多行
    worksheet.insert_rows(insert_start_row, total_insertions)
    
    # 设置每一行的内容和样式
    for i, insertion_data in enumerate(insertions):
        actual_row = insert_start_row + i  # 连续的行号
        # ... 设置单元格数据和样式 ...
```

### 2. 动态位置跟踪 `working_groups`

**目的**：实时跟踪每个测试项的当前位置，避免位置计算错误

```python
# 创建工作副本
working_groups = {k: v.copy() for k, v in test_item_groups.items()}

# 每次插入后更新位置
for item_name, item_info in working_groups.items():
    if item_name != next_test_item and item_info['first_row'] >= insert_start_row:
        item_info['first_row'] += rows_inserted
        item_info['last_row'] += rows_inserted
```

### 3. 有序处理策略

**策略**：始终处理`first_row`最小的测试项，确保插入顺序与原始表单顺序一致

```python
while all_matches:
    # 找到下一个要处理的测试项（按first_row排序的第一个）
    next_test_item = None
    min_first_row = float('inf')
    
    for test_item_name in all_matches.keys():
        current_first_row = working_groups[test_item_name]['first_row']
        if current_first_row < min_first_row:
            min_first_row = current_first_row
            next_test_item = test_item_name
```

## 匹配算法优化

### 分层智能匹配策略

1. **检测特殊关键词**：识别表单测试项是否包含"边界测试"、"性能测试"等特殊关键词

2. **分情况处理**：
   - **表单项有特殊关键词**：
     - 优先精确匹配
     - 再尝试核心名称匹配（去除特殊关键词后匹配），要求数据库项也包含相同关键词
   - **表单项为普通项**：
     - 使用双向包含匹配
     - 过滤掉包含特殊关键词的数据库项

3. **防重复匹配**：使用`record_matched`标志，确保同一数据库记录不会因为多个`||`分隔的名称而重复匹配

```python
def _match_test_items(cls, form_test_name: str, asset_data: List[Dict]) -> List[Dict]:
    """分层智能匹配策略"""
    
    special_keywords = ['边界测试', '性能测试', '压力测试', '负载测试']
    
    # 检测表单测试项是否包含特殊关键词
    form_has_special = any(keyword in form_test_name for keyword in special_keywords)
    
    if form_has_special:
        # 特殊项处理逻辑
        # 1. 优先精确匹配
        # 2. 核心名称匹配 + 关键词验证
    else:
        # 普通项处理逻辑
        # 1. 双向包含匹配
        # 2. 过滤特殊关键词
```
