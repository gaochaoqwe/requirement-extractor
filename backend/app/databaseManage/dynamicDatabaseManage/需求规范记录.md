# 组织资产管理模块需求规范记录

## 已实现功能总结

### 1. 数据自动排序功能 📊
- **核心功能**: 所有数据自动按照软件类别进行排序，顺序为：通用、随动、图像、红外、激光、分色滤光、手柄
- **技术实现**: 数据库添加 `category_order` 和 `item_order` 排序字段，CRUD操作自动维护排序
- **默认数据**: 为每个软件类别预置至少2条默认测试数据
- **前端展示**: 删除合并单元格功能，采用统一的表格行展示

### 2. Excel导入功能 📥
- **普通导入**: 支持Excel文件导入（软件类别、测试项名称、测试内容、测试方法）
- **智能匹配**: 根据测试项名称进行模糊匹配，匹配成功则追加内容（自动编号），匹配失败则新增记录
- **文件处理**: 自动读取Excel第一个工作表，仅验证表头格式，支持.xlsx 和 .xls 格式
- **API接口（普通导入）**: `/api/database/requirements/import/normal`

#### 2.1 多Sheet（7列）导入（新增）
- **功能**: 支持一个 Excel 文件中包含 4 个 Sheet（转塔、对抗告警、光雷、吊舱），各 Sheet 结构统一为 7 列；按 Sheet 名映射到对应表。
- **导入模式**: `full`（清空后导入）与 `incremental`（仅新增，判重跳过）。
- **文件限制**: 仅支持 `.xlsx`。
- **统计返回**: 每个 Sheet 返回 `created`、`skipped`、`deleted`（仅全量）。
- **API接口（多Sheet导入）**: `/api/database/requirements/import/multisheet-7cols?mode={full|incremental}`
- **后端实现位置**: `backend/app/databaseManage/dynamicDatabaseManage/services/RequirementService.import_multisheet_7cols`

### 3. Excel风格用户界面 🎨
- **工具栏设计**: Excel 风格 Ribbon，按钮为“上图标下文字”。
- **自定义图标**: 本地 SVG 资源，统一视觉风格。
- **表格样式**: 仿 Excel 的行号、列标题、网格线。
- **多行文本**: 测试项描述/方法支持多行。
- **普通导入入口（重要UI细节）**:
  - 主按钮文案固定为“普通导入”。
  - 点击弹出 Popover，内含“全量导入”“增量导入”两个按钮，分别触发文件选择并携带 `mode`。
  - 弹层宽度严格以“普通导入”四字的实际文字宽度为基准动态计算（测量 `ref=importMainText`），加入少量内边距余量，避免换行。
  - 通过 `:popper-style` 和 `.el-popover.import-popover` 覆盖默认 `min-width`，并使用 `width: fit-content` 消除右侧空白与“偏左”错觉；内容容器 `margin: 0 auto` 居中。
  - 配色：常态中性浅灰；悬浮时全量=绿色系、增量=琥珀系，以弱化但可感知的语义区分。

### 4. 交互操作功能 🖱️
- **右键菜单**: 实现Excel风格的右键上下文菜单，支持复制、粘贴、插入行、删除等操作
- **键盘快捷键**: 
  - `Ctrl+F`: 打开搜索对话框
  - `Ctrl+A`: 全选表格单元格（不影响浏览器全选）
  - `Ctrl+S`: 手动保存数据
  - `Ctrl+C/V/X`: 复制、粘贴、剪切操作
- **单元格编辑**: 支持双击单元格进入编辑模式，点击其他位置自动退出编辑

### 5. 行选择与操作 📋
- **多种选择方式**: 
  - 单击行号：选择单行
  - Ctrl+单击：多行选择
  - Shift+单击：范围选择
  - 拖拽行号：连续选择多行
- **行操作**: 支持选中行的复制、粘贴、插入、删除等操作
- **视觉反馈**: 选中行高亮显示，提供清晰的视觉反馈

### 6. 自动换行功能 📏
- **智能计算**: 根据列宽和单元格内容自动计算所需行高
- **动态调整**: 启用自动换行时，所有行高自动调整以完整显示内容
- **全选应用**: Ctrl+A全选后自动应用换行设置
- **开关控制**: 工具栏提供自动换行开关，可随时启用/禁用

### 7. 搜索功能 🔍
- **搜索界面**: 独立的搜索对话框，支持高级搜索选项
- **搜索选项**: 支持区分大小写、全词匹配等选项
- **结果导航**: 提供"查找上一个"和"查找下一个"按钮
- **结果高亮**: 搜索结果在表格中高亮显示
- **快捷访问**: Ctrl+F快捷键快速打开搜索

### 8. 数据持久化策略 💾
- **自动保存**: 实现防抖保存机制，数据变更后自动保存到后端
- **手动保存**: Ctrl+S快捷键支持手动保存
- **状态提示**: 界面显示数据是否有未保存的更改
- **批量操作**: 支持批量数据更新和保存

### 9. 代码架构说明 🏗️（修正）
- **核心视图**: `frontend_vue/src/views/databaseManage/dynamicDatabaseManage/DatabaseManage.vue` 集成 Ribbon、表格与导入交互。
- **服务层**: `backend/app/databaseManage/dynamicDatabaseManage/services/requirement_service.py` 实现普通导入与多Sheet导入逻辑。
- **通用CRUD**: `.../db/crud.py` 针对四张七列表提供通用批量处理、清空、判重等能力。
- **Excel工具**: `.../utils/excel_utils.py` 负责解析多Sheet七列结构。

### 10. 错误处理与稳定性 🛡️
- **导入容错**: Excel导入时提供详细的错误信息和处理建议
- **模块导入**: 后端模块导入失败时提供降级方案，确保应用正常启动
- **用户反馈**: 操作成功/失败时提供明确的用户反馈信息
- **异常恢复**: 编辑状态异常时自动恢复到安全状态

## 技术栈说明

### 后端技术
- **框架**: FastAPI + SQLAlchemy + SQLite
- **Excel处理**: openpyxl库
- **数据库**: SQLite with 自定义排序字段

### 前端技术  
- **框架**: Vue 3 + Composition API
- **UI库**: Element Plus + 自定义Excel风格组件
- **构建工具**: Vite
- **图标资源**: 本地SVG图标库

## 部署与联调说明
- **后端端口**: 5002（FastAPI）。
- **前端开发**: `npm run dev`（Vite 代理到后端）。
- **数据库**: 自动初始化，可通过管理接口重置。
- **文件上传**: 支持普通导入与多Sheet导入。

### 端到端联调（推荐使用脚本）
- **环境**: Conda 环境 `aiTest_new`；安装依赖 `backend/requirements.txt`，脚本依赖 `requests`。
- **样例生成脚本**:
  - 全量样例：`temp/generate_sample_multisheet_7cols.py`
  - 增量样例：`temp/generate_sample_multisheet_7cols_incremental.py`
- **联调脚本**：`temp/test_multisheet_import.py`
  - 检查后端健康 `/health`
  - 调用 `/api/database/requirements/import/multisheet-7cols?mode=full` 与 `mode=incremental`
  - 自动打印各 Sheet 的 created/skipped/deleted 统计
  - 执行顺序：先 full 再 incremental

### API 摘要
- 普通导入：`POST /api/database/requirements/import/normal`
- 多Sheet导入：`POST /api/database/requirements/import/multisheet-7cols?mode={full|incremental}`
- 七列表分页：`GET /api/database/requirements/seven/list?table=转塔|对抗告警|光雷|吊舱`
- 七列表导出：`GET /api/database/requirements/seven/export?table=...`
