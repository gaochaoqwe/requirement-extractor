# OCR数据提取优化说明

## 📋 概述

OCR识别模块已经优化，现在支持**传统算法**和**AI算法**两种数据提取模式。推荐使用传统算法，速度更快，准确性相当。

## 🚀 性能对比

| 算法类型 | 处理时间 | 准确性 | 依赖性 | 推荐度 |
|---------|---------|--------|--------|--------|
| **传统算法** | ~0.009秒 | 高 | 无外部依赖 | ⭐⭐⭐⭐⭐ |
| AI算法 | ~3-10秒 | 高 | 需要OLLAMA服务 | ⭐⭐ |

**性能提升**: 传统算法比AI算法快约**100-1000倍**！

## 🔧 配置方式

### 方式1: 配置文件控制（推荐）

编辑 `ocr_config.py` 文件：

```python
OCR_CONFIG = {
    # True: 使用传统算法（推荐）
    # False: 使用AI算法
    "USE_TRADITIONAL_ALGORITHM": True,
}
```

### 方式2: 代码直接指定

```python
from data_extractor import DataExtractor

# 使用传统算法（推荐）
extractor = DataExtractor(use_traditional_algorithm=True)

# 使用AI算法
extractor = DataExtractor(use_traditional_algorithm=False)

# 从配置文件读取（默认）
extractor = DataExtractor()
```

## 📝 使用示例

```python
from data_extractor import DataExtractor

# 初始化提取器（默认使用传统算法）
extractor = DataExtractor()

# OCR文本示例
ocr_text = """
申请人: 雷宇博
申请部门: 总体部
机型: 雷霆
项目主管总师: 周山明
主任设计师: 任伟霆
"""

# 提取数据
result = extractor.extract_form_data(ocr_text)
```

## 🔄 迁移指南

### 从AI模式切换到传统模式

1. **修改配置文件**:
   ```python
   # ocr_config.py
   "USE_TRADITIONAL_ALGORITHM": True
   ```

2. **重启服务**: 重启后端服务使配置生效

3. **验证效果**: 上传测试图片验证提取效果

### 回退到AI模式（如需要）

1. **修改配置文件**:
   ```python
   # ocr_config.py  
   "USE_TRADITIONAL_ALGORITHM": False
   ```

2. **确保OLLAMA服务运行**: AI模式需要OLLAMA服务支持

## 🐛 故障排除

### 问题1: 传统算法初始化失败
**解决方案**: 检查导入路径，确保 `traditional_data_extractor.py` 文件存在

### 问题2: 字段提取不准确
**解决方案**: 
1. 检查OCR文本格式
2. 添加新的正则表达式规则
3. 更新错别字纠正映射

### 问题3: 部门推断失败
**解决方案**: 
1. 检查 `domain_mapping_config.json` 配置
2. 添加新的部门映射规则
3. 完善关键词匹配逻辑
