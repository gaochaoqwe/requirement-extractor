# 全局过滤规则配置说明

## 快速开始

编辑 `global_filter_rules.json` 文件来配置全局过滤规则。

## 规则结构

```json
{
  "id": "rule_xxx",           // 唯一标识
  "name": "规则名称",          // 显示名称
  "keywords": ["关键词"],      // 匹配的关键词列表
  "logic": "AND",             // "AND" 或 "OR"
  "enabled": true,            // 是否启用
  "description": "说明"        // 规则说明
}
```

## 逻辑类型

- **AND**: 问题原因**同时包含所有**关键词才过滤
  ```json
  {"keywords": ["数组", "可能"], "logic": "AND"}
  // 匹配: "数组操作可能越界"
  // 不匹配: "数组操作" 或 "可能越界"
  ```

- **OR**: 问题原因**包含任一**关键词就过滤
  ```json
  {"keywords": ["硬编码", "魔法数字"], "logic": "OR"}
  // 匹配: "使用了硬编码值" 或 "魔法数字0x100"
  ```

## 启用/禁用规则

```json
{
  "enabled": false  // 设为 false 禁用此规则
}
```

## 添加自定义规则

在 `rules` 数组末尾添加：

```json
{
  "id": "rule_custom_001",
  "name": "我的自定义规则",
  "keywords": ["关键词1", "关键词2"],
  "logic": "AND",
  "enabled": true,
  "description": "自定义过滤规则说明"
}
```

## 注意事项

1. 修改后需要**重启后端服务**才能生效
2. 关键词匹配**不区分大小写**
3. 规则对**所有任务全局生效**
4. 被过滤的问题状态设为3（已过滤），前端显示为灰色
