## 📈 Token使用估算

```
典型中型项目（50个文件，5000行代码）

阶段1：功能发现
  ├─ 项目结构分析: ~500 tokens
  ├─ 入口函数代码: ~300 tokens
  ├─ AI提示词: ~1000 tokens
  ├─ AI响应: ~800 tokens
  └─ 小计: ~2600 tokens

阶段2：审查执行（假设发现5个功能）
  
  功能1审查（系统初始化）:
    ├─ 系统提示词: ~800 tokens
    ├─ 初始任务: ~200 tokens
    ├─ 轮1 (get_file_outline): 300 + 200 = 500 tokens
    ├─ 轮2 (search_function): 200 + 150 = 350 tokens
    ├─ 轮3 (get_function_context): 200 + 400 = 600 tokens
    ├─ 轮4 (输出问题): 500 tokens
    └─ 小计: ~3150 tokens
  
  功能2-5审查: 3150 * 4 = 12600 tokens
  
  总计（阶段2）: 3150 + 12600 = 15750 tokens

总消耗: 2600 + 15750 = 18350 tokens ✅

远低于60000 tokens限制！

对比旧版（可能失败的情况）：
  - 一次性加载全部调用图: 8000 tokens
  - 一次性生成全部链路: 12000 tokens
  - 批量审查所有链路: 45000 tokens
  - 总计: 65000 tokens ❌ 超限！
```
